# 第4・第5段階 検証記録

対象バージョン: TNote 1.3.0+8

## このWindows開発PCで完了した確認

- `flutter analyze`: 問題なし。
- `flutter test`: 34件すべて成功。
- 左上に保存ファイル名を表示し、上段タイトル名とは独立していることを確認。
- 上段タイトルを17px・太字で表示し、クリップボードの文章を貼り付けできることを画面テストで確認。
- 最新版判定、24時間制限、手動確認、版のスキップ、ネット未接続時の通常起動をテストで確認。
- 上段の複数タイトルと各タイトル内のタブを1つの`.tnote`へ保存し、まとめて再読込できることを確認。
- 従来形式の`.tnote`を読み込み、複数タイトル対応形式へ更新できることを確認。
- ウィンドウの×ではタイトル画面へ戻らず終了し、未保存確認がファイル全体に一度だけ出ることを確認。
- ファイルメニューに「上書き保存」と「ファイルに保存」が表示されることを確認。
- 日本語の連続入力、フォント欄の削除、システム標準フォント、任意文字サイズ、Excel風テーマ色パレットを画面テストで確認。
- 保存後に変更がない場合の確認なし終了と、起動時に復元確認を表示しないことを確認。
- 設定画面と上部の取扱説明、アプリバージョン連動を確認。
- 下段タブに×がなく、右クリックメニューに「名前を変更」「複製」「削除」があることを確認。
- 同じ保存先の`.tnote`を二つの端末相当で開くと、後から開く側の通常オープンを拒否できることを確認。
- 後から読み取り専用で開いた文書へ編集を試みても内容が変わらず、保存が失敗し、元の`.tnote`が変わらないことを確認。
- Windows 11 x64 Releaseビルド、インストーラー、ポータブル一式を作成。

## macOS実機で確認する項目

1. `flutter build macos --release`が成功する。
2. Finderで`.tnote`をダブルクリックするとTNoteで開く。
3. 新規保存と別名保存で任意の保存先を選べる。
4. OneDrive上のWindows版作成ファイルを読み書きできる。
5. Windowsで同じファイルを先に開くと、Mac側に読み取り専用の確認が日本語で出る。
6. 「はい」で閲覧だけができ、「いいえ」で対象ファイルが閉じる。
7. 複数ウィンドウ、Command+S、終了時の保存確認を確認する。
8. 配布用の署名、公証、Gatekeeperでの起動を確認する。

## iPhone実機で確認する項目

1. Xcodeから実機へインストールして起動する。
2. ファイルアプリとOneDriveから既存`.tnote`を開く。
3. 新規保存、別名保存、編集、上書き、終了、再起動、再オープンを確認する。
4. 文字入力中にキーボードで本文やタブが隠れないことを確認する。
5. TXT/Markdownの保存先選択と共有シートを確認する。
6. Windows・Macで作成した日本語、書式、複数タブを保持することを確認する。

Apple向けビルド、署名、Finder関連付け、iOSファイルアプリとOneDrive File ProviderはmacOSとXcodeを必要とするため、このWindows PCだけでは実機確認できません。
